# Dialektoz

Plataforma para aprender inglés — ruta por niveles (A1–C1), editor de lecciones por
bloques, gamificación y certificación verificable.

La aplicación vive en [`apps/web`](./apps/web) (Next.js 16 + React 19 + Supabase +
Cloudflare R2, desplegada en Vercel). Consulta su [README](./apps/web/README.md) para
el stack completo, la puesta en marcha y la arquitectura.

```bash
cd apps/web
npm install
npm run dev
```
